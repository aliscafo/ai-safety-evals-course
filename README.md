# Inspect AI: evals coursework & experiments

Hands-on work with [Inspect](https://inspect.aisi.org.uk/) (UK AISI's evaluation framework), from an AI safety evals course.

## Contents
- **week_1** — Inspect fundamentals: tasks, datasets, solvers (`system_message`, `chain_of_thought`, `multiple_choice`), reading eval logs.
- **week_2** — Evaluating LLMs on MMLU: dataset → `Sample` mapping, running evals across models, parsing `EvalLog` into DataFrames, and statistical analysis of results — bootstrap confidence intervals and how CI width shrinks with sample size.
